# 后端只读检查

## 适用场景

当用户要求：

- 检查后端问题；
- 排查接口问题；
- 检查登录接口；
- 检查鉴权；
- 分析报错；
- 分析后端代码；

使用本 Skill。

## 核心规则

本 Skill 默认只读。

不要修改、创建、删除或覆盖项目文件。

## 检查流程

1. 确认当前项目目录。
2. 检查 `back/` 目录结构。
3. 检查实际 Python 版本。
4. 检查依赖文件。
5. 根据实际代码确认 Web 框架。
6. 找到与用户问题相关的路由。
7. 检查对应的接口实现。
8. 根据需要检查服务层、数据访问层、数据库配置和鉴权配置。
9. 分析问题原因。
10. 给出具体文件位置和问题依据。

## 禁止行为

- 不要因为目录名称猜测框架。
- 不要自动修改代码。
- 不要自动安装依赖。
- 不要自动修改数据库。
- 不要自动修改配置。
- 不要为了验证而执行具有修改效果的命令。

## 输出

使用中文输出：

1. 检查范围
2. 发现的问题
3. 问题原因
4. 涉及文件
5. 建议修改方案
6. 是否需要用户确认
