# 前端只读检查

## 适用场景

用户要求检查：

- Vue 页面；
- 组件；
- 路由；
- Axios；
- 登录；
- 接口调用；
- 页面报错；
- 构建问题；

时使用。

## 项目技术栈

实际代码优先，本项目当前记录为：

- Vue 3
- Vite
- Vue Router
- Element Plus
- Axios
- JavaScript
- npm

## 检查流程

1. 检查 `vue-project/`。
2. 检查相关页面。
3. 检查相关组件。
4. 检查路由。
5. 检查 `src/api/`。
6. 检查状态管理。
7. 检查相关样式。
8. 检查接口调用和错误处理。
9. 根据实际代码分析问题。

## 只读要求

本 Skill 默认不修改文件。

不要：

- 修改代码；
- 安装依赖；
- 修改 `package.json`；
- 修改构建配置；
- 删除文件。
